# tienda-demo

Tienda online de **Cerámica Demo** (empresa ficticia): catálogo, ficha de producto y carrito.

- Bun + TypeScript, Hono con JSX en servidor, SQLite (`bun:sqlite`).
- Envío gratuito a partir de 60 €; si no, 4,95 €.

```sh
bun install
bun run db:seed
bun run dev
```

Consulta [CONTRIBUTING.md](CONTRIBUTING.md) para el flujo de trabajo.
